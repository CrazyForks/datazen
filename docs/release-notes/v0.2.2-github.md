## DataZen v0.2.2

基于 **Tauri v2 + Rust + React** 构建的轻量跨平台数据库桌面客户端，自 v0.2.1 以来累计 **820** 次提交。

本版主线：**可视化查询构建器**、**Redis 工作台重做**、**数据库隧道**，以及一次**驱动契约硬切换（Driver API v4）**。

### ⚠️ 给插件作者

**Driver API `PROTOCOL_VERSION` 3 → 4，是硬切换**：`(database, schema)` 维度不再由会话隐式携带。

- `get_tables` / `get_table_schema` / `get_columns` / `get_all_columns` / `dump_*_ddl` 现在显式接收 `database` + `schema`
- **删除 `use_database`**——宿主不再在读取前发 `USE` 语句
- 新增 `has_schema_level()` / `default_schema()`；`validate_schema_target(driver, database, schema, scope)` 是双方共用的唯一校验规则
- `SchemaScope::{AnySchema, ExactSchema}`：列举类方法可接受「全部 schema」，解析类方法必须指定一个

**所有外部驱动必须重新编译。** 低于宿主 `PROTOCOL_VERSION` 的驱动会被拒绝或降级运行。Kiwi 与 Superset 已于 2026-09-21 在各自 `main` 跟进该契约。

### 🐛 重点修复

- **SchemaCache 污染（BUG-003）**：先打开 ER 图会读取非当前会话的数据库并切换共享会话，随后把**零列结果**以 300s TTL 写进缓存。此后所有读取都命中被污染的条目——网格行数正确但单元格为空、结构视图无列、ER 图表格无列。随 v4 契约一并根治。
- **MySQL SQL 字面量反斜杠转义缺失**（注入风险），并补充双引号转义以兼容 Navicat。
- 切换到从未打开过的连接时不再沿用上一个连接的面板状态。
- Redis 字面量检索由精确键匹配改为按前缀搜索。

### 🌐 语言包补齐

- **9 个宿主语言包全部对齐英文源**（德 / 西 / 法 / 日 / 韩 / 巴葡 / 俄 / 简中 / 繁中）：补齐 172 个缺失 key、移除 20 个已废弃 key。简中此前不被 `i18n-sync-check` 覆盖，本次一并纳入审计。

## English

A lightweight, cross-platform desktop database client built with **Tauri v2 + Rust + React**, with **820** commits since v0.2.1.

### ⚠️ For plugin authors

**Driver API `PROTOCOL_VERSION` 3 → 4 is a hard cut.** The `(database, schema)` dimension is no longer carried implicitly by the session.

- `get_tables` / `get_table_schema` / `get_columns` / `get_all_columns` / `dump_*_ddl` now take `database` + `schema` explicitly
- **`use_database` is deleted** — the host no longer issues a `USE` statement before each read
- New `has_schema_level()` / `default_schema()`; `validate_schema_target(driver, database, schema, scope)` is the single rule both sides call
- `SchemaScope::{AnySchema, ExactSchema}` — listing methods may accept "all schemas", resolution methods require one

**Every external driver must be rebuilt.** Drivers below the host's `PROTOCOL_VERSION` are rejected or run in degraded mode. Kiwi and Superset adopted the contract on their `main` branches on 2026-09-21.

### 🐛 Notable fixes

- **SchemaCache poisoning (BUG-003)**: opening the ER diagram first switched the shared session and cached a **zero-column** result under a 300s TTL. Every later read hit the poisoned entry — right row counts but empty cells, no columns in the structure view, column-less ER tables. Fixed together with the v4 contract.
- **MySQL SQL literal backslash escaping** (injection risk), plus double-quote escaping for Navicat compatibility.
- Switching to a never-opened connection no longer reuses the previous connection's panel state.
- Redis literal lookup is now a prefix search instead of an exact key match.

### 🌐 Translations

- **All 9 host locale packs now match the English source** (de / es / fr / ja / ko / pt-BR / ru / zh-CN / zh-TW): 172 missing keys added, 20 obsolete keys removed. Simplified Chinese was not covered by `i18n-sync-check` and has now been audited as part of this pass.
- **All 9 Redis driver locale packs** synced with 247 missing keys added, matching the driver's `en.ts` exactly.
- New v0.2.2 terminology (tunnels, Visual Query Builder, object tree) is now consistent across every language; placeholder parity verified key by key.
- Also fixed a batch of long-standing mistranslations — e.g. German "Host" was rendered as "Gastgeber", Spanish "Logging" as "Explotación florestal", Brazilian Portuguese "Condition" as "Doença".

## 安装说明 / Installation

### macOS

> The app is not Apple-notarized. After installation, run in Terminal:
>
> ```
> xattr -cr /Applications/DataZen.app
> ```
>
> Or: right-click the app → Open → confirm in the dialog.

### Windows

- **NSIS installer**: run `DataZen-*-windows-x64.exe` and follow prompts
- **Portable**: unzip `DataZen-*-windows-x64-portable.zip`, run `DataZen.exe` directly

### Linux (x86_64)

- **AppImage**: `chmod +x DataZen-*.AppImage` then run (may need `libfuse2`)
- **deb**: `sudo apt install ./DataZen-*-linux-x64.deb`
- **rpm**: `sudo rpm -i ./DataZen-*-linux-x64.rpm`
- Runtime dependency: WebKitGTK (`libwebkit2gtk-4.1-0` / `webkit2gtk4.1`)
