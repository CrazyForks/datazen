## DataZen v0.2.1

基于 **Tauri v2 + Rust + React** 构建的轻量跨平台数据库桌面客户端，自 v0.1.2 以来累计 **589** 次提交。

### ✨ 重点新功能

**🚀 首次运行引导向导（Onboarding Wizard）**
3 步快速上手：连接示例数据库 → 探索 AI 辅助 → 开始使用。内置 SQLite 示例库，支持 8 种语言，引导进度可恢复。

![首次运行引导向导](https://raw.githubusercontent.com/flyxl/datazen/main/site/assets/screenshots/wizard-open.png)

**🎯 SQL 编辑器 4 模式执行策略**
- **Run Current**（默认）：基于 AST 自动识别光标所在单条 SQL，只执行该句
- **Run Selection**：仅执行鼠标高亮选中的代码块
- **Run All**：执行完整批处理或多段 DDL
- **Ask**：每次执行前弹出策略确认窗

![Statement Gutter 与执行按钮](https://raw.githubusercontent.com/flyxl/datazen/main/site/assets/screenshots/pro-01-statement-gutter.png)

**💡 意图操作灯泡菜单（Intentions）**
光标停在 `*` 上，行号槽自动亮起灯泡，悬停即出操作菜单：一键把 `*` 展开为完整列清单、给裸列名补上表限定符，或把完整列清单收回 `*`。展开/限定/收回三种意图可循环往复，`Alt-Enter` 快捷键同时保留。

![意图操作菜单](https://raw.githubusercontent.com/flyxl/datazen/main/site/assets/screenshots/pro-06-intentions.png)

**⚡ Paste as IN 批量导入**（`Cmd+Shift+V` / `Ctrl+Shift+V`）
从表格或日志复制多行 ID，在 `IN ()` 内一键格式化为 `'a', 'b', 'c'` 格式。

![Paste as IN 批量导入](https://raw.githubusercontent.com/flyxl/datazen/main/site/assets/screenshots/pro-08-paste-as-in.png)

**🛑 高危执行拦截**
- 无 WHERE 的 UPDATE/DELETE 自动弹出红色警告弹窗，要求二次确认
- 占位符未填值时直接拦截，防止隐式 NULL 导致全表更新

![高危执行拦截](https://raw.githubusercontent.com/flyxl/datazen/main/site/assets/screenshots/30-sql-editor-danger-guard.png)

设置页自定义代码片段，实时注入编辑器补全。

A lightweight, cross-platform desktop database client built with **Tauri v2 + Rust + React**, with **589** commits since v0.1.2.

### ✨ Highlights

**🚀 Onboarding Wizard**
3-step guided first run: connect sample DB → explore AI → start working. Built-in SQLite sample DB, 8 languages, resumable progress.

**🎯 SQL Editor 4 Execution Modes**
- **Run Current** (default): AST-based single statement execution at cursor position
- **Run Selection**: execute only highlighted code block
- **Run All**: execute full script or multiple DDL statements
- **Ask**: prompt for confirmation before each execution

**💡 Intention Lightbulb Menu**
Put the caret on `*` and a lightbulb lights up in the gutter — hover for the action menu: expand `*` into the full column list, qualify bare columns with their table, or collapse a complete column list back to `*`. The three intentions cycle, and `Alt-Enter` still works.

![Intention action menu](https://raw.githubusercontent.com/flyxl/datazen/main/site/assets/screenshots/pro-06-intentions.png)

**⚡ Paste as IN** (`Cmd+Shift+V` / `Ctrl+Shift+V`)
One-click format multiple lines of IDs into `IN ('a', 'b', 'c')` syntax.

**🛑 Dangerous Execution Guard**
- Auto-popup warning for UPDATE/DELETE without WHERE clause, requiring confirmation
- Blocks unbound parameters to prevent accidental NULL propagation

**✨ SQL Snippets Management**
Custom code snippets in Settings, injected into editor autocomplete in real-time.

**🔧 Toolbar Overflow Menu**
Query Toolbar restructured into 4 functional zones with auto-collapsing overflow dropdown on narrow screens.

**🔌 Extension Points Hot-Plug**
Runtime SQL Editor Pro extensions (hover previews, FK JOIN completion, signature help), CodeMirror Compartment dynamic reconfiguration, package signature verification.

**🌙 Dark Theme Overhaul**
Full dark theme token refresh, light theme refinement, unified semantic `--color-accent-*` tokens.

**🌐 i18n Domain Packs**
14 domain packs with lazy loading for sub-windows, reducing initial JS bundle. 8 languages fully synced.

**🏗️ Four-Dimensional Extension System**
Driver (compile-time DB drivers) / Theme (visual themes) / EP (runtime extension points) / Wapp (Workspace Apps) — plugin ecosystem foundation.

**🧠 Multi-Model AI Support**
OpenAI, Anthropic, DeepSeek, Ollama, and custom endpoints. Local models get relaxed context; public models auto-masked. One-click SQL error diagnosis.

**📊 Query Result to Chart**
One-click switch between line, bar, pie, scatter charts with PNG/SVG export.

**🗄️ Built-in Redis Driver**
Key tree browsing, CLI, real-time Monitor, Pub/Sub.

**🔐 Security Hardening**
IPC error auto-masking (passwords, tokens, file paths); SQL Guard enhanced to catch write verbs in comments.

## 安装说明 / Installation

### macOS
> The app is not Apple-notarized. After installation, run in Terminal:
> ```
> xattr -cr /Applications/DataZen.app
> ```
> Or: right-click the app → Open → confirm in the dialog.

### Windows
- **NSIS installer**: run `DataZen-*-windows-x64.exe` and follow prompts
- **Portable**: unzip `DataZen-*-windows-x64-portable.zip`, run `DataZen.exe` directly

### Linux (x86_64)
- **AppImage**: `chmod +x DataZen-*.AppImage` then run (may need `libfuse2`)
- **deb**: `sudo apt install ./DataZen-*-linux-x64.deb`
- **rpm**: `sudo rpm -i ./DataZen-*-linux-x64.rpm`
- Runtime dependency: WebKitGTK (`libwebkit2gtk-4.1-0` / `webkit2gtk4.1`)
