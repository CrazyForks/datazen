# PRD: 可视化查询构建器（Visual Query Builder）

> Feature ID: `QUERY_BUILDER` · Version: `1.0.0` · Status: Draft

## 1. 背景与动机

DataZen 的核心查询入口是基于 CodeMirror 的 SQL 编辑器，适合熟悉 SQL 的用户。但以下场景存在明显痛点：

- **探索性查询**：用户不确定表名/列名，需要先查 Schema 再手写 SQL。
- **复杂 JOIN**：多表关联查询的 ON 条件、字段选择编写繁琐且易出错。
- **条件组合**：嵌套 `AND`/`OR` 条件在纯文本编辑器中难以可视化管理。
- **新用户门槛**：不熟悉 SQL 语法的用户需要频繁查阅文档。

**可视化查询构建器**通过图形化界面（拖拽、勾选、下拉）降低上述门槛，同时生成标准 SQL 并可直接在 SQL 编辑器中执行。

## 2. 目标用户

| 角色 | 使用场景 |
|------|---------|
| 数据分析师 | 探索性分析，快速筛选/聚合数据 |
| 产品经理 | 非技术人员查看数据，不需要学 SQL |
| 开发者 | 快速构建复杂 JOIN，再微调手写 SQL |
| DBA | 教学/演示 SQL 生成过程 |

## 3. 功能范围（v1.0）

### 3.1 核心功能（Must Have）

| 功能 | 描述 |
|------|------|
| **表/视图选择** | 从当前数据库的 Schema 树中选择一个或多个表/视图 |
| **列选择** | 勾选需要查询的列，支持 `table.column` 限定名 |
| **WHERE 条件构建** | 可视化构建单个条件（字段 + 操作符 + 值），支持 `AND`/`OR` 逻辑组 |
| **ORDER BY** | 选择排序字段和方向（ASC/DESC），支持多列排序 |
| **GROUP BY** | 选择分组字段 |
| **聚合函数** | 对列应用 `COUNT`/`SUM`/`AVG`/`MIN`/`MAX` |
| **SQL 预览** | 实时生成并显示对应 SQL 语句 |
| **一键应用** | 将生成的 SQL 插入/替换 SQL 编辑器内容 |
| **方言适配** | 根据数据库类型生成符合方言的 SQL |

### 3.2 增强功能（Should Have，v1.1）

| 功能 | 描述 |
|------|------|
| **JOIN 支持** | 基于外键关系或手动指定的 ON 条件添加 JOIN |
| **DISTINCT** | 勾选 DISTINCT 选项 |
| **LIMIT/OFFSET** | 设置分页参数 |
| **HAVING** | 聚合后的筛选条件 |
| **子查询预览** | 将构建器当前配置作为子查询嵌入外层 |

### 3.3 不在范围内（v1.0）

- INSERT/UPDATE/DELETE 等写操作构建（风险较高，留待后续版本）
- 存储过程/函数调用构建
- 多数据库跨库查询构建
- 查询模板保存与分享

## 4. 用户交互流程

```
用户打开查询标签页
    ↓
点击工具栏「可视化构建」按钮
    ↓
构建器面板展开（与 SQL 编辑器并列或覆盖）
    ↓
  ┌─ 选择表/视图 ─→ 勾选列 ─→ 配置条件/排序/分组
  │                                    ↓
  │                           实时 SQL 预览更新
  │                                    ↓
  └──────────────────── 点击「应用到编辑器」
                                    ↓
                          SQL 编辑器内容更新
                                    ↓
                            用户可手动微调后执行
```

## 5. 非功能需求

| 维度 | 要求 |
|------|------|
| **性能** | 加载 Schema 元数据（表列表 + 列信息）< 500ms；SQL 预览实时更新无感知延迟 |
| **可用性** | 键盘导航支持（Tab 切换字段、Enter 确认、Esc 取消） |
| **响应式** | 窗口宽度 < 800px 时构建器切换为纵向堆叠布局 |
| **国际化** | 中英文完整支持，UI 文本纳入 i18n 体系 |
| **可访问性** | 所有交互元素可聚焦、有 ARIA 标签 |

## 6. 验收标准

1. 用户可以从当前连接的数据库中选择表并勾选列，生成正确的 SELECT 语句。
2. WHERE 条件支持 `=`、`!=`、`>`、`<`、`>=`、`<=`、`LIKE`、`IN`、`IS NULL`、`IS NOT NULL` 操作符。
3. 条件组支持 `AND`/`OR` 嵌套（至少两层）。
4. 生成的 SQL 可以在 SQL 编辑器中直接执行并返回正确结果。
5. 对 PostgreSQL、MySQL、SQLite 三种方言生成语法正确的 SQL。
6. 单元测试覆盖 SQL 生成逻辑核心路径。
