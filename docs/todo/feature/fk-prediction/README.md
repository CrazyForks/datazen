# 外键关系智能预测

在数据库**没有声明外键约束**的情况下，推断表之间真实的关联关系，供可视化查询构建器
（自动 JOIN）与 ER 图共用。

- [设计方案](./design.zh-CN.md) — 信号分层、打分模型、架构落点、20 条坑清单、分期建议

## 为什么需要

大量真实系统不建 FK 约束（ORM 主导、遗留库、数仓、分片表）。这些库在 QB 里拖进两张表后
一条 JOIN 都不会自动出现 —— 而这恰恰是最需要辅助的场景。

## 核心原则

> **匹配错 > 匹配不到。** 一条错误的 JOIN 会把结果算错且用户未必看得出来；
> 漏掉一条，用户手工补一次即可（手动 JOIN 已实现）。

因此：预测必须**可解释、可撤销、分置信度档位**，且永远不与声明式 FK 混为一谈。
