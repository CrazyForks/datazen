# 轨道台账目录约定

每个 `<track-id>/` 下：

- `progress.md` —— 状态机、commit、心跳、自验/复验记录（单写者序列：Coder → Tester → Coder → Tester…每棒接手即改头部）。
- `bugs/<track-id>-BUG-nnn.md` —— **一 Bug 一文件**，文件名 = Bug ID。正文归登记 Tester；修复者只改 `- **状态**：` 行并追加 `## 修复记录（round-N）`；复测者追加 `## 复测记录（round-N）` 并改判。开放态：`待修复 / 修复中 / 待复测 / 待验证`；关闭态：`已修复 / 撤回 / 裁定不修`。
- `bugs/README.md` —— 可选，轮次索引与「无缺陷」记录。
- 历史轨的单文件 `bugs.md` 保持**只读**（聚合脚本双格式计数），不再新增。

设计动机：多代理（Tester / 修复 Coder / 复测 Tester、以及并行轨道的合并面）共写一个账本文件必然产生合并冲突与写锁争议；按 Bug ID 拆分后每个文件的写者序列独立，git 合并天然正交。
