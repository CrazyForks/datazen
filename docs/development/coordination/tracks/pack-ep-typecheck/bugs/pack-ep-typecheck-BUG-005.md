# pack-ep-typecheck-BUG-005 — a retired codegen leaves two live references that claim it still exists

- **Track**: pack-ep-typecheck
- **Status**: OPEN — finding only, deliberately not fixed (belongs to the `i18n-drivers` track that retired the codegen)
- **Files**: `.gitignore:64`, `scripts/check-driver-import-boundaries.mjs:88-94`

## The gap

`src/extensions/generated-locales.ts` is no longer produced by anything, but two
places still behave as though it is:

1. `.gitignore:64` lists it under
   `# Driver selection codegen (written by resolve-drivers.mjs; not committed)`.
2. `scripts/check-driver-import-boundaries.mjs:94` lists it in
   `SKIPPED_CODEGEN_FILES`, under a doc comment (lines 88–90) asserting
   `` `src/extensions/generated*.ts` … is regenerated by `scripts/resolve-drivers.mjs` ``.

## Evidence (真实管线实测)

- `git ls-files src/extensions/generated-locales.ts` → empty. It is not tracked.
- `grep -n "generated-locales" scripts/resolve-drivers.mjs` → no match.
  `resolve-drivers.mjs` writes only `generated.ts` (line 820) and `driver_init.rs`
  (line 1333).
- A repo-wide search for `generated-locales` outside `node_modules` returns exactly
  one hit: the string constant at `check-driver-import-boundaries.mjs:94`. Nothing
  imports the file.

So the `.gitignore` rule ignores a file nothing writes, and the boundary checker's
doc comment describes a regeneration path that no longer exists. The
`SKIPPED_CODEGEN_FILES` entry is harmless-but-dead; the comment above it is the part
that actively misleads, because it generalises from `generated.ts` (still written) to
`generated*.ts` (no longer a single thing).

## Why it was not fixed in passing

This track's task for `.gitignore` was one specific line (`*.incomplete`). Editing
`check-driver-import-boundaries.mjs` would have put a 32-error file owned by another
track into this branch, and deleting a `.gitignore` line whose file might be revived
by a later codegen change is not a call this track should make unilaterally.

## Suggested fix (owner: the track that retired the codegen)

- Drop `src/extensions/generated-locales.ts` from `.gitignore:64`, or replace the
  stale entry with whatever codegen *is* current.
- Remove the `SKIPPED_CODEGEN_FILES` entry, and narrow the doc comment at lines
  88–90 to `src/extensions/generated.ts` — the one file `resolve-drivers.mjs`
  actually writes.

## Note for whoever works in this worktree

A copy of `src/extensions/generated-locales.ts` may exist in a fresh track worktree
because it was hand-copied from the main checkout before this was measured. It is
untracked and gitignored, so it cannot reach a commit, and nothing reads it. It is
safe to delete.
